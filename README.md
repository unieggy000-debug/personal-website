# Carol — 个人网页

苏联太空时代美学个人作品集

**在线预览：** https://personal-website-roan-rho-56.vercel.app/。

## 本地开发

```bash
git clone https://github.com/unieggy000-debug/personal-website.git
cd personal-website
pnpm install   # 或 npm install
pnpm dev       # http://localhost:3001
```

## 部署 Vercel


## 技术栈

- Next.js 16 · TypeScript · Tailwind CSS v4
- GSAP ScrollTrigger · Lenis 平滑滚动
- 长图视差背景 · 拼贴贴纸 · 自定义飞船光标

## 页面结构

| Section | ID | 说明 |
|---------|-----|------|
| 首页 | `#home` | 海报标题 + 中文副标题 |
| 简介 | `#about` | 档案卡、曲线时间线 |
| 作品 | `#works` | 横向 Pin 档案画廊 |
| 页脚 | `#site-footer` | 底部拼贴 |

## 快捷键

- `1` `2` `3` — 跳转首页 / 简介 / 作品
- `ESC` — 关闭作品详情弹窗
